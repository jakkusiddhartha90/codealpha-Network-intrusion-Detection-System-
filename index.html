INCIDENT RESPONSE PLAYBOOK

What should an analyst do?

  1. Validate: check whether the source IP and signature match approved activity.
  2. Investigate: review related events and the original Suricata log.
  3. Escalate: notify the network owner if activity remains suspicious.
  4. Contain safely: use approved firewall or isolation procedures only after authorization.
  5. Document: record the decision and mark the alert reviewed.

This training project does not automatically block devices. Alerts are indicators and require human validation.
